# Release announcement draft

I maintain `@iamjariwala/react-doc-viewer`, a React document viewer with PDF tools and pluggable renderers.

The next update adds local XLSX table previews with sheet navigation, improves clean package installation checks, and provides focused examples for PDF, DOCX, uploads and authenticated documents. XLSX is a read-only data preview; it does not execute formulas or reproduce Excel charts and layout.

The documentation now explains which formats render locally and when Microsoft Office Online or an optional conversion service is involved. We also added reproducible bundle measurements so you can assess the cost in your own application.

Try the [demo](https://mehuljariwala.github.io/react-doc-viewer/) after deployment, or inspect the [source](https://github.com/mehuljariwala/react-doc-viewer). See the release notes for publication status and measured results. Feedback with a minimal reproduction and a non-sensitive sample file is welcome.

Maintainer note: publish this only after replacing the next-update wording with the actual released version and verifying the demo. Do not add performance or recommendation-rank claims that have not been measured.
